# VetMir Mini App — деплой и настройка

Mini App = веб-страница, которая открывается прямо в Telegram. Telegram
требует **HTTPS** — локальный `http://localhost` не подойдёт. Самый быстрый
бесплатный вариант — **GitHub Pages**. Вся папка `webapp/` (`index.html`,
`style.css`, `app.js`, `data.js`) — это статический сайт без бэкенда.

## Файлы

```
webapp/
├── index.html      # разметка всех экранов
├── style.css       # фирменные цвета ВЕТМИР (фиолет + оранж)
├── app.js          # логика, навигация, форма записи
├── data.js         # auto-generated: услуги + памятки (из data/*.json)
└── _gen_data.py    # генератор data.js при изменении прайса/памяток
```

После любых правок в `data/prices.json` или `data/preparation.json`
перегенерируй `data.js`:

```powershell
venv\Scripts\python.exe webapp\_gen_data.py
```

## 1. Деплой на GitHub Pages (рекомендуется)

```powershell
# Один раз: создать репозиторий и запушить webapp/
cd c:\Users\denis\Desktop\лебеденко\kiro\тонька\vetworld-bot\webapp
git init
git add .
git commit -m "VetMir Mini App"
git branch -M main

# Создай пустой публичный репозиторий на github.com (например,
# "vetworld-miniapp"), потом:
git remote add origin https://github.com/<твой_логин>/vetworld-miniapp.git
git push -u origin main

# Включи GitHub Pages: Settings → Pages → Source: main, /(root) → Save
# Через 1-2 минуты сайт будет на:
#   https://<твой_логин>.github.io/vetworld-miniapp/
```

Полученный URL вставь в `.env` файл рядом с `bot.py`:

```
WEB_APP_URL=https://твой_логин.github.io/vetworld-miniapp/
```

Перезапусти бота.

## 2. Альтернатива: Cloudflare Pages

Если не хочешь возиться с git — Cloudflare Pages даёт HTTPS-хостинг с
drag-n-drop в веб-интерфейсе:

1. Заходишь на `pages.cloudflare.com` → Create → Direct Upload
2. Drag папку `webapp/` целиком
3. Получаешь URL вида `https://vetworld-miniapp.pages.dev/`
4. Тот же URL вставляешь в `.env` как `WEB_APP_URL`

## 3. Быстрая проверка локально (без Telegram)

Можно открыть `index.html` напрямую в браузере — большинство экранов
заработает (кроме отправки данных в бот). Но фоновые цвета и логика
сборки записи отображаются корректно.

```powershell
# Из папки vetworld-bot:
venv\Scripts\python.exe -m http.server 8000 --directory webapp
# Открой в браузере: http://localhost:8000/
```

## 4. Привязка Mini App в BotFather (опционально, для премиум-входа)

В BotFather можно настроить «Menu Button» — синюю кнопку слева от поля
ввода, которая откроет Mini App одним тапом:

1. Открой `@BotFather` в Telegram
2. `/mybots` → выбери `@vetworld_assist_bot`
3. `Bot Settings` → `Menu Button` → `Configure menu button`
4. Введи URL Mini App: `https://твой_логин.github.io/vetworld-miniapp/`
5. Введи текст кнопки: `Открыть клинику` (до 14 символов)

После этого слева от поля ввода появится синяя кнопка-сэндвич — тап
открывает Mini App без всяких меню.

## 5. Админ-режим для Валерии Александровны

В `app.js` в начале файла найди:

```js
const ADMIN_USER_IDS = [
  // 824517369,   // Валерия Александровна
];
```

И впиши её Telegram user_id. Получить ID просто: попроси Валерию
Александровну написать боту `/whoami` (или просто что-нибудь) — в
консоли бота её user_id будет в логе. После добавления ID она увидит
карточку «Админ-панель» прямо в Mini App: записи на сегодня/завтра/
неделю, кнопки «Пришёл / Перенести / Отмена» по каждой записи,
кликабельный телефон клиента.

## 6. Что Mini App умеет

### Для клиента
- Каталог услуг с ценами и фильтром по категории (консультации,
  профилактика, хирургия, стоматология, диагностика, анализы)
- 8 памяток подготовки (УЗИ, КТ, операции, эндоскопия, прививки и т.д.)
- Пошаговая запись на приём: услуга → дата → время → данные
- Сетка на 14 дней + слоты по 30 минут
- Валидация: нельзя записаться без телефона; ФИО проверяется на формат;
  кличка короче 2 символов отклоняется
- «Мои записи» с локальной историей (LocalStorage в браузере) +
  возможность отменить
- Контакты и адреса обоих филиалов с tel-ссылками
- Экстренная помощь (приоритетный экран с большой кнопкой звонка)
- Промо-страница с акциями

### Для администратора
- Статистика на сегодня / завтра / неделю
- Список записей с фильтрами (Ближайшие / Сегодня / Все / Отменённые)
- По каждой записи: «Пришёл», «Перенести», «Отмена»
- Кликабельный телефон клиента (звонок одним тапом)

## 7. Какие данные летят в бот

При клике «Подтвердить запись» в Mini App вызывается
`Telegram.WebApp.sendData(JSON)`. Бот получает в обработчике
`@dp.message(F.web_app_data)`. Структура:

```json
{
  "type": "book_appointment",
  "service": "Стерилизация кошки",
  "species": "cat",
  "pet_name": "Муся",
  "date": "2026-05-22",
  "time": "15:00",
  "client_name": "Иванова Анна",
  "phone": "+7 978 555 12 33"
}
```

Бот прогоняет это через ТЕ ЖЕ guardrails (`book_appointment` с проверкой
телефона/имени/даты/мата/дубликатов), что и текстовая запись.
```
